## 次にやること

### 1. 区画ごとの再構成誤差を測る (仮説の確認)

**これが M2 の行き止まりを抜ける唯一の入口である．** 校正で分かったのは，
再構成検査が画像全体で 1 つの割合しか見ていないために，

- 補間・圧縮による**一様な**滲み
- 非整数倍リサイズによる**距離に比例した**ずれ

が同じ数に潰れている，ということ．画面を原点からの距離で区切り，区画ごとの不一致率を
測れば分かれる **はず** — まだ確かめていない．

やること: `grid-eval/` の画像から，リサイズなし (補間あり) の件とリサイズありの件を
選び，正解の $(s, d)$ で再構成したときの不一致率を区画ごとに出して比べる．
**分かれてから設計を変える．** 分かれなければ別の入口を探す (自己相関の非整数周期を
直接測る，など) ．

### 2. 数値の校正 (1 の後)

決めるもの: $\varepsilon$ ・$\delta$ ・$\tau$ ・信頼度閾値 ・$w_L$ ・窓サイズ．
道具は揃っている．

```sh
cargo run -p px-calib --release -- gen      # 合成 500 件 (種 0 で再現する)
cargo run -p px-calib --release -- sweep    # 検証 300 件を掃引
cargo run -p px-calib --release -- report   # 指標と運転点
```

- **検証セットで決め，テストセットでの再調整はしない．** テストセットにはまだ
  1 度も触れていない
- 採点の定義は掃引 CSV からやり直せる (`Row::outcome` は行の内容から毎回求める) ．
  定義を変えても掃引はやり直さなくてよい
- **リサイズありの件の正解は「棄却」である** (整数の格子が存在しないため) ．
  $\mathrm{round}(s \cdot r)$ は正解にしない — 理由は `sweep::Outcome` の doc コメント
- 選ぶ指標は**マクロ平均**．素の正解率だと「ほぼ全部棄却」が勝つ (格子なしが 2/3)

## 落とし穴

実装中に踏んだもの．**同じ穴に落ちないこと．**

| 落とし穴 | 対処 |
| --- | --- |
| `Turn(chain)` をラン長の最小値で決める | 単発ジャギーを毎回見逃す．**G2 の曲率場から求める** (D60) |
| 単調区間を符号の反転だけで分ける | L 字の角が 1 本になる．**主軸に直交する歩みが 2 歩続いたら区切る** (D61) |
| `.hex` でアルファ 0 の色を飛ばす | 以降の添字が全部ずれる．**透明も 1 行として書く** |
| 局所格子推定で平坦な窓を投票させる | 「窓に収まる最大の $s$」が選ばれる．**信頼度 0 は投票しない** |
| `Srgb` へ変換してから成分を切り詰める | 色相がずれる．**`clip_to_gamut` で色相を保つ** |
| ディザ検出の入れ替わり率を 0.5 超に置く | ランダムディザを 1 件も拾えない (期待値が $2p(1-p) \le 0.5$) |
| 領域ラベリングを 8 連結にする | 市松が 1 領域になりディザ検出が壊れる．**4 連結** |
| 校正の成績を素の正解率で選ぶ | 「ほぼ全部棄却」が 1 位になる (格子なしの件が 2/3) ．**マクロ平均で選ぶ** |
| 試験の一時ファイルを全試験で共有する | `fs::write` が中身を空にする隙に別の試験が読み，稀に落ちる．**試験ごとにディレクトリを分ける** |

## 決まっている作法

- 日本語は読点 `，` 句点 `．`
- 閾値には**暫定である旨を doc コメントに書く**．根拠が無い数字を黙って置かない
- 決定論性の 3 規則 (設計書 6.15) を守る．同点には必ずタイブレークを付ける
- `testdata/` は CC0 原則．**MIT は著作権表示を同梱すれば受け入れる** (例外を
  `testdata/SOURCES.md` に明記済み) ．CC-BY / CC-BY-SA / GPL は除外
- このリポジトリの `.md` に「generated by Claude Code」フッタは付けない
  (Obsidian vault 側は付ける)
