## 次にやること

### 1. $s_*$ と $2 s_*$ を分ける情報を探す (M2 の唯一の関門)

**ここが詰まっている．** 誤棄却 48.5% の犯人は再構成検査と位相ずれ検査だが，
検査を緩めても成績は上がらない — 構図がこうなっている．

| 再構成検査 | 起きること |
| --- | --- |
| **入れる** ($\tau = 0.1$) | 真の $s$ が落ちる → 約数が「閾値を満たす最大の $s$」として勝つ (**過小推定**) |
| **外す** ($\tau = 1.0$) | $2 s_*$ が通る (**過大推定**) ．マクロは 67.5% → 65.2% で変わらない |

**再構成検査は $2 s_*$ を止める唯一の関門であり，同時に真の $s$ を落としている．**

測って潰した案 (`px-calib recon`，均衡正解率)．

| 案 | 結果 |
| --- | --- |
| 全画素の不一致率 (現行) | 74.0% |
| セル内側だけを見る (滲みは境界に集中するはず) | 76.9% — **+2.9 では採らない** |
| $\bar{V}(s) / \bar{V}(s/2)$ (倍数なら半分で分散が激減するはず) | 54.8% — **当てずっぽう** |

2 つめが外れた理由は測ってから分かった: **真の $s$ の約数も同じ振る舞いをする**
($s_*/2$ のセルも平坦) ．分けたい相手は倍数だけではない．

**セル再構成に基づく単一統計は 77% 前後で頭打ちである．** 位相ずれ検査 (D62) が
「絵の中身に依らない量」で 95.9% を出したのと同じ筋で，別の情報を探すこと．

> [!warning] 実装してから測らない
> このセッションだけで仮説を 2 つ潰した．どちらも作り込んでから外れと分かる類である．
> `px-calib recon` に統計を足して**均衡正解率で比べてから**手を動かす．

## 校正の道具 (`px-calib`)

```sh
# 合成データセット (元絵は CC0 の実物 64 件)
cargo run -p px-calib --release -- gen                 # 種 0 で再現する
cargo run -p px-calib --release -- sweep               # 検証 300 件を掃引
cargo run -p px-calib --release -- report              # 指標と運転点

# 測定の口 (推定の経路ではない．仮説を測ってから実装するために使う)
cargo run -p px-calib --release -- bands               # 帯ごとの再構成誤差と位相
cargo run -p px-calib --release -- confidence          # 信頼度の各項
cargo run -p px-calib --release -- recon               # 再構成統計の分離能
cargo run -p px-calib --release -- diagnose            # 実データの誤棄却を 1 件ずつ解剖

# 実データ枠
cargo run -p px-calib --release -- real                # 同梱 148 件
cargo run -p px-calib --release -- real --dir testdata/grid-eval/real/local   # 92 件
```

- **検証セットで決め，テストセットでの再調整はしない**
- 採点の定義は掃引 CSV からやり直せる (`Row::outcome_at` は行の内容から毎回求める) ．
  **$\mathrm{min\_confidence}$ は掃引をやり直さずに掃ける** — 掃引は 0 で回している
- **リサイズありの件の正解は「棄却」である** ($\mathrm{round}(s \cdot r)$ は正解にしない)
- 選ぶ指標は**マクロ平均**．素の正解率だと「ほぼ全部棄却」が勝つ (格子なしが 2/3)

### 校正した既定値

$\varepsilon = 0.2$ (**画像分散に対する割合**) ・$\delta = 0.1$ ・$\tau = 0.1$ ・
帯 4 ・許容 $\theta = 1/6$ ・帯あたり最小セル数 2 ・$\mathrm{min\_confidence} = 0.03$

### 素材の状況 (格子推定の分はすべて調達済み)

| 用途 | 状態 |
| --- | --- |
| 合成データの種 | 64 件 (CC0．Kenney 16x16 が 32 ・Dungeon Crawl 32x32 が 32) ．**実データ枠とは重ならない** |
| 実データ 同梱 | 148 件 (正例 94 / 負例 54) |
| 実データ `local/` | 92 件 (正例 23 / 負例 69) ．再配布不可なので追跡しない |
| lint 正例 / 負例 | **未** |

`ingest` は入力の素性で縮小のしかたを変える．**どれを選んでも正解は「こちらが決めた
拡大倍率」**なので，推定器を自分の出力で採点することにはならない．

| 指定 | 入力 |
| --- | --- |
| (既定) | 見かけの周期が読める絵 |
| `--force-period P` | 周期が読めない絵 (AI 出力など) |
| `--recover-native` | 非整数倍で拡大されて配られた絵 (元絵を厳密に復元する) |
| `--native` | 元絵そのままの素材 (CC0 のタイル) |
| `--keep-refused` | 上のどれでもない絵 → **負例**として取り込む (棄却が正解) |

> [!warning] 閾値の最良点は合成と実データで食い違っていた
> 元絵を差し替える前は $\mathrm{min\_confidence}$ が 0.03 対 0.01，$\delta$ が 0.1 対
> 0.2 と 2 度続けて逆を向いた．**2 度続いたら疑うのは閾値ではなくデータセットの側**
> である — 実際，元絵を実物へ替えたら食い違いはほぼ消えた．

## 落とし穴

実装中に踏んだもの．**同じ穴に落ちないこと．**

| 落とし穴 | 対処 |
| --- | --- |
| `Turn(chain)` をラン長の最小値で決める | 単発ジャギーを毎回見逃す．**G2 の曲率場から求める** (D60) |
| 単調区間を符号の反転だけで分ける | L 字の角が 1 本になる．**主軸に直交する歩みが 2 歩続いたら区切る** (D61) |
| `.hex` でアルファ 0 の色を飛ばす | 以降の添字が全部ずれる．**透明も 1 行として書く** |
| 局所格子推定で平坦な窓を投票させる | 「窓に収まる最大の $s$」が選ばれる．**信頼度 0 は投票しない** |
| `Srgb` へ変換してから成分を切り詰める | 色相がずれる．**`clip_to_gamut` で色相を保つ** |
| ディザ検出の入れ替わり率を 0.5 超に置く | ランダムディザを 1 件も拾えない (期待値が $2p(1-p) \le 0.5$) |
| 領域ラベリングを 8 連結にする | 市松が 1 領域になりディザ検出が壊れる．**4 連結** |
| 帯ごとの位相を帯の左端基準で測る | 帯ごとに違う物差しになる．**画像の原点を基準に測る** |
| 帯の実験で再構成検査を切る ($\tau = 1$) | 過大推定が野放しになる．問いは「今の検査が通した答えを選り分けられるか」である |
| 信頼度の対照群に小さい $s$ を入れる | $\bar{V}(s)$ は $s$ とともに単調に増えるのでマージンが負に潰れる (D63) |
| 校正の成績を素の正解率で選ぶ | 「ほぼ全部棄却」が 1 位になる．**マクロ平均で選ぶ** |
| 試験の一時ファイルを全試験で共有する | 稀に落ちる．**試験ごとにディレクトリを分ける** |
| **エラー文を「落ち方」と読み違える** | `real` の「信頼度が下限を下回った」は**最終的な答え**の話で，真の $s$ を何が落としたかではない．**`px-calib diagnose` で見る** |
| 正解の無い件と「格子が無い件」を同じ `unknown` にする | 誤受理が見えない．**`no_grid` を立てて棄却が正解として採点する** |
| 「入力が拡大済みか」を周期推定や元絵復元で判定する | 短い軸では当てずっぽうになる (48 件中 5 件 / 24 件を誤って拒否した) ．**$k \times k$ ブロックの一様性を厳密に見る** |
| 負例を縮小して保存する | 補間が「格子が無い」という性質を触る．**中央を切り出す**．面積は中立ではない |
| `--force-period` に実際のブロックの約数を指定する | $s$ と $2s$ が両方成立し**正解が一意に決まらない**．拒否する |
| `ingest` の連番を毎回 0 から振る | 同じ区分へ 2 回取り込むと 1 回目を黙って上書きする (**24 件消した**) |
| 旗で既定値を潰す (`--normalize-epsilon`) | 旗が無いと `false` になり**既定と違う設定で測ってしまう**．`Option<bool>` にする |
| ダウンロード素材をそのまま読ませる | `com.apple.quarantine` が付いていると EPERM で落ちる．**`xattr -cr` してから渡す** |

## 決まっている作法

- 日本語は読点 `，` 句点 `．`
- 閾値には**暫定である旨を doc コメントに書く**．根拠が無い数字を黙って置かない
- 決定論性の 3 規則 (設計書 6.15) を守る．同点には必ずタイブレークを付ける
- `testdata/` は CC0 原則．**MIT は著作権表示を同梱すれば受け入れる** (例外を
  `testdata/SOURCES.md` に明記済み) ．CC-BY / CC-BY-SA / GPL は除外．
  再配布できないものは `grid-eval/real/local/` (追跡しない)
- このリポジトリの `.md` に「generated by Claude Code」フッタは付けない
  (Obsidian vault 側は付ける)
- **測ってから直す．** 設計や閾値を変える前に必ず測る — このセッションだけで仮説を
  2 つ潰しており，先に実装していたら 2 つとも作り込んでいた
