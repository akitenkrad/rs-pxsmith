# `.aseprite` の往復検証はどこまで独立か — R3 の残り (D167)

- 測った日: 2026-08-15
- 測る口: `cargo test -p px-io --test aseprite_independent_parse -- --nocapture`
- 素材: `testdata/aseprite/aseprite-tests/` の 19 件

## 結論

**独立化できたのは «読み手» で，«素材» はまだ独立していない．**

| 何が | 状態 |
| --- | --- |
| **読み手** | **独立させた** — 公開仕様だけから 2 つ目のパーサを書き，`aseprite-io` の解釈と突き合わせる |
| **素材** | **独立していない** — 19 件は `aseprite-io` 自身の fixtures 由来．**最新版 Aseprite で作ったファイルが要る** |

道具は**この差を黙らなくなった** — 往復試験が «19 件がバイト一致した
(うち独立素材 0 件)» と言い，0 件のときは «R3 は閉じていない» と併記する．

## バイト一致は «理解した» の証明ではない

`aseprite_roundtrip.rs` は読み込み → 書き出しがバイト一致することを確かめる．
これは保持層が汚れないことの証明としては正しいが，**`aseprite-io` が中身を
正しく解釈したことの証明にはならない**．

未知のチャンクを不透明な塊として持ち回って書き戻すだけでもバイトは一致する．
そして **`Document::project` は «解釈した側» を読む**ので，レイヤの取り違えや
セルの取りこぼしは**往復試験を素通りして，出てくる絵だけが静かに変わる**．

> [!note] **これは D164 と同じ形である．**
> «試験が通る» と «働いている» は別で，何を検査していないかを言わないと，
> 通った数がそのまま安心の根拠に読まれる．

## 2 つ目の読み手を仕様から書いた

`crates/px-io/tests/aseprite_independent_parse.rs` は公開仕様
(`ase-file-specs.md`) の欄の並びだけから書いた最小のパーサである．
**`aseprite-io` の実装は見ずに書く** — 実装を写したら同じ誤りを 2 回書くことに
なり，突き合わせる意味が消える．

比べるのは «絵を組み立てるのに要る事実» に絞った:

| 比べるもの | 食い違うと何が起きるか |
| --- | --- |
| 画布 ・コマ数 | 絵の寸法が変わる |
| **コマごとの表示時間** | 合計が合っていても並びが違えば動きが変わる |
| レイヤの並び ・名前 | 別のレイヤを描く |
| **グループがどれか** | 作業層の添字が丸ごとずれる |
| パレットの長さ ・透明添字 | 色が化ける |
| **コマごとのセルの有無** | 空でないコマが空になる (またはその逆) |

**19 件すべてで食い違いは 0 件だった．**

> [!warning] **通る試験は «守っている» の証明ではないので，壊して確かめた．**
> 仕様側のレイヤ種別をわざと 1 ビット反転させると
> «中身を持つレイヤの並びが食い違う» で落ち，リンクセルの解決を無視させると
> «コマ 1 ・レイヤ 1 のセルの有無が食い違う» で落ちる．**どちらも歯があった．**

> [!warning] **突き合わせが空振りでないことも数えた** (D163 の作法)．
> 素材にグループが 1 つも無ければ «グループを取り違えない» は何も検査していない
> のと同じである．実測: **グループ 5 ・タイルマップ 4 ・リンクセル 37 ・
> 複数コマ 12 件 ・色深度 3 種**．リンクセルは 4 ファイルで実際に解決している．

## 19 件が覆っていないもの (**推測ではなく数えた**)

### 1 件も現れないチャンク ・セル種別

| 種別 | 備考 |
| --- | --- |
| **cel extra (0x2006)** | 実在する機能．セルの精密な位置 |
| **生のセル (type 0)** | 圧縮しない保存．新しい版では出ないかもしれない |
| old palette (0x0011) | 古い版の遺物 |
| mask (0x2016) ・path (0x2017) | **仕様が «使われていない» と明記している** |

試験 (`the_corpus_records_what_it_does_not_cover`) が毎回数え直すので，
素材が増えればこの一覧は自動で縮む．**知らないチャンクが出たら落ちる**ようにも
してある — 仕様が増えたか，こちらが読み違えているかのどちらかだからである．

### 現れはするが 1 通りしかないもの

| 項目 | 19 件の実測 |
| --- | --- |
| ブレンドモード | **52 レイヤすべて `normal`** |
| レイヤ不透明度 | 255 が 47 ・0 が 5．**中間の値が 1 つも無い** |
| グループの深さ | `child_level` は **0 と 1 だけ** (入れ子が無い) |
| 色プロファイル | **19 件すべて sRGB** (埋め込み ICC が無い) |
| 画布 | **最大 64x64** |
| コマ数 | **最大 12** |
| パレット | **2 〜 32 色** (256 色を使い切る例が無い) |
| タグの向き | forward ・reverse ・ping-pong (**ping-pong reverse が無い**) |

**ここに無い書き方は，2 つの読み手のどちらも試していない．**

## 残っていること

`testdata/aseprite/independent/` に**最新版 Aseprite で作ったファイル**を置く．
何を作ればよいかは同ディレクトリの `README.md` に上の表から起こしてある．
置くだけで往復試験も突き合わせも自動で拾う (どちらも再帰的に走査する)．

**これは人が Aseprite を操作しないと作れない**ので，ここで止めてある．
