# Godot BMFont UI example

This Godot 4.7 project displays two `Label` nodes backed by AngelCode BMFont
files generated by pxsmith. The first label uses the Misaki Gothic BDF and
shows `SCORE 0120` plus a Japanese line. The second uses the synthetic GPOS
fixture and shows `AV`, whose advance includes a -1 px kerning adjustment.

Both fonts use white RGBA glyph pages with transparent backgrounds. The labels
keep a white font colour; use the Label `font_color` or `modulate` property to
colour a monochrome font. The viewport is 128×32 pixels, uses nearest-neighbour
texture filtering, and is captured without window scaling.

## Rebuilding the assets

From this directory, run:

```sh
./make_assets.sh
```

Set `PXSMITH=/path/to/pxsmith` to use an existing binary. Otherwise the script
builds the workspace binary. It writes `misaki.fnt`, `misaki_0.png`,
`gpos.fnt`, and `gpos_0.png`. It also renders `misaki_expected.png` and
`gpos_expected.png` directly with `pxsmith font render` for pixel comparison.
Intermediate `.pxfont.toml` files are kept in a temporary directory.
The script also writes `window.png` and the three 9-slice reference images
`window-stretch-30x22.png`, `window-tile-30x22.png`, and
`window-tile-fit-30x22.png`. It packs the three window modes and the larger
`hero_body` fixture into `ui.png` / `ui.sheet.json`, then writes the three
`window_*.stylebox.tres` resources with `pxsmith export godot`. The project
setting `textures/canvas_textures/default_texture_filter=0` keeps imported
textures nearest-neighbour; pxsmith does not write Godot `.import` files.

## Running and capturing

Open `project.godot` in Godot 4.7, or run from the repository root:

```sh
godot --path examples/godot-ui
godot --path examples/godot-ui -- --capture /tmp/ui.png
```

The capture mode waits for three rendered frames, saves the unscaled viewport,
and quits. Compare the capture rectangle `(0, 0, 56, 16)` with
`misaki_expected.png` after replacing transparent pixels with the background
colour. Compare `(0, 20, 11, 8)` in the same way with `gpos_expected.png`.

Godot creates `.import` files and the `.godot/` cache on import. They are not
part of this example; `.godot/` is ignored by Git.

To capture the 9-slice scene with Godot 4.7, run:

```sh
godot --path examples/godot-ui res://nineslice.tscn -- --capture /tmp/9.png
```

Compare the capture regions `(0, 0, 30, 22)`, `(32, 0, 30, 22)`, and
`(64, 0, 30, 22)` pixel-for-pixel with the stretch, tile, and tile-fit
reference images respectively. The background is opaque, so transparent
pixels in a future window fixture remain visible in the capture.

To capture the same three modes through the generated `StyleBoxTexture`
resources, run:

```sh
godot --path examples/godot-ui res://stylebox.tscn -- --capture /tmp/sb.png
```

Compare `/tmp/sb.png` at the same three rectangles with
`window-stretch-30x22.png`, `window-tile-30x22.png`, and
`window-tile-fit-30x22.png`. For example, ImageMagick can crop each rectangle
before a pixel comparison:

```sh
magick /tmp/sb.png -crop 30x22+0+0 /tmp/sb-stretch.png
magick compare -metric AE /tmp/sb-stretch.png \
  examples/godot-ui/window-stretch-30x22.png null:
```
